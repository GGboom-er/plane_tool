# Matrix Ribbon System (MRS) - 避坑沉淀记录

[更新模式报错]→[根因: 打组改变绝对路径]→[正确方案: split('|')[-1]解构引用]→[避坑规则: 节点名缓存严禁信任长路径]

[孤立节点泄露]→[根因: 物理手柄被删致GC遍历失效]→[正确方案: 将DG纯算法节点强杀指令置于挂载判定外]→[避坑规则: GC回收绝不能绑定在Transform级联上]

[万向节空间翻转]→[根因: 全球空间下Blend跨越180度误差]→[正确方案: 转入Local Space推演逆向变化]→[避坑规则: 空间链融合必须降维到子控件空间]

[工具属性热载]→[根因: 旧输出端口被霸占导致断联]→[正确方案: 在挂载新算符时强制执行断开与清理循环]→[避坑规则: Update模式必须前置彻底的解绑除旧动作]

[带偏差子层生成绑定]→[根因: 首节大纲父组驻留原点，未补偿物理跟随目标偏差]→[正确方案: 动态追加 parent_object.WS * outlinerParentInverse 的 OPM 修正]→[避坑规则: 严禁将大纲组层级位置等同于物理变换参考系]


[重复保护粗暴切断层级穿透]→[根因: 新功能拦截窗口生硬另立门户]→[正确方案: 利用 while True 重推原生组件]→[避坑规则: 任何用户端干预不得摧毁原有操作循环系]

[原生循环开销指数级累加]→[根因: 徒手在 Python 虚拟机中拆解 16 维 MMatrix 与单位阵的比对]→[正确方案: 直接调用底层 C++ 绑定的 isEquivalent(kIdentity, 0.001)]→[避坑规则: 复杂几何及矩阵判断严禁在解译器层执行]

[解绑误删骨架连环案]→[根因: 移除绑定结构时未剥离宿主]→[正确方案: 将骨架 parent_object 至目标或世界坐标]→[避坑规则: 大纲清算前必须执行强制断交隔离]

[系统弹窗拦截命名流]→[根因: 强加报错阻断了用户焦点]→[正确方案: 在捕获命名冲突时静默复用重推 QInputDialog]→[避坑规则: 不允许在流程闭环中强行阻隔原生窗口]

[生成尺寸不符合默认]→[根因: 工具脚本内部缩放计算导致了扭曲与旧场景残骸重叠复用]→[正确方案: 剥离固定系数干预，强制清除或告知用户清理旧骨架残留并重启工具 UI 防止内存缓存]→[避坑规则: 测试必须覆盖完整的热重载 (Reload) 逻辑以及确保测试环境的大纲整洁度]

[层级视图出现双黄蛋平铺重复]→[根因: 新建的分组被在顶层方法循环时直接又添入了根集合节点]→[正确方案: 拦截底层组加入最高级的父节点集合列表循环操作]→[避坑规则: 集合层级的关系应当遵循单一子父对应原则，打包操作必须排除内部小分组结构]

[MCP远程调试静默失败]→[根因: 远程测试脚本存在类名拼写错误但由于包裹在裸 try-except 中导致致命崩溃未被打印]→[正确方案: 工具验证脚本必须完整捕获 traceback.format_exc() 并返回给监控端]→[避坑规则: 严禁在自动化黑盒验证与 MCP 远程驱动流中吞没异常抛错，防止失去排障线索]
